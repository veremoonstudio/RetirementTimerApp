# План реализации клона Retirement Timer

Клонирование приложения для отслеживания времени до выхода на пенсию с использованием Jetpack Compose и современной архитектуры Android (MVVM).

## Предлагаемые изменения

### Тема и Ресурсы
*   **Цвета**: Настройка цветовой схемы Material 3 (бежевый фон `#F5F5DC`, темно-коричневый текст, синие акценты для кнопок и переключателей).
*   **Шрифты**: Подбор шрифтов, максимально похожих на оригинальные.

### Модели данных и Хранилище
*   **[NEW] Models.kt**: Определения `RetirementSettings`, `Holiday`, `TimeUnits`.
*   **DataStore**: Использование Jetpack DataStore для сохранения даты выхода на пенсию и настроек рабочего времени.

### Бизнес-логика (ViewModel)
*   **[NEW] RetirementViewModel.kt**:
    *   Логика расчета «Общего времени» (Total Time).
    *   Сложная логика расчета «Рабочего времени» (Work Time): исключение выходных, праздников, учет рабочих часов и часов отпуска.
    *   Обновление таймера каждую секунду через `StateFlow`.

### Экраны (UI)
*   **[MODIFY] MainActivity.kt**: Настройка навигации и контейнера приложения.
*   **[NEW] MainScreen.kt**:
    *   Верхняя панель с переключателем и кнопками "Premium", "Background".
    *   Текст с датой и заголовком.
    *   Сетка обратного отсчета (Days, Hours, Min, Sec).
    *   Floating Action Button (FAB) с иконкой календаря для быстрого выбора даты.
*   **[NEW] SettingsScreen.kt**:
    *   Выбор рабочих дней (Checkbox Row).
    *   Выбор единиц времени.
    *   Выбор времени начала/конца дня (TimePicker).
    *   Список праздников с возможностью добавления.
*   **[NEW] BackgroundScreen.kt**: Сетка с изображениями (заглушки для начала).
*   **[NEW] PremiumScreen.kt**: Карточки с тарифами.

## План верификации

### Автоматизированные тесты
*   Unit-тесты для `RetirementViewModel` для проверки точности расчетов рабочего времени.

### Ручная проверка
*   Сравнение UI со скриншотами на эмуляторе.
*   Проверка сохранения настроек после перезапуска приложения.
